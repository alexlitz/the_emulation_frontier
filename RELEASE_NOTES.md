# The Emulation Frontier: release notes

Snapshot: the top 10,000 most-downloaded text-generation checkpoints on the Hub (newest model created 2026-11-09).
Every number below is computed by the code in this tree: `python -m graph.post_numbers` writes the values of the
post's placeholders and the release keys to `dist/release_numbers.json` (a generated file, not tracked).

## What is in this release

### The relation and the frontier

- 4,384 distinct configs, 3,906 classified decoder LMs (77 speculative drafters dropped), 942 arch+size shapes.
- Headline (payable) frontier: **293** maximal models (279 autoregressive + 14 non-AR: diffusion, block-causal,
  prefix-LM). Exact 320, mixgap 265, capacity 49 (if every type wall were free); 1 for the elephantine.
- `FRONTIER.md`, regenerated by `python -m graph.frontier` (unchanged by this integration: the merged branches add
  tests and references, not rules).
- 29 mutual pairs (shapes that emulate each other both ways). With every round-3 key off (before the code-level
  reading) the headline would be 246.

### The universal host (elephantine)

- One host, `elephantine/universal.py`, carries 3,900 of the 3,906 models (every mixer family but five has a tested
  branch; open: Cyrah, whose code is in a gated repo, and five models with unclassified recurrences).
- Loaded and tested: 3,531 of the 3,900 carried models are accepted by a whole-model `from_*` loader that a test runs
  against that model_type's own code (151 model types; 2,093 models with a released checkpoint of their type
  checked). No test that runs remote code is credited (`tests/conftest.py` REMOTE_CODE_TESTS;
  `--include-remote` / `include_remote=True` in `elephantine.loader_coverage` and `graph.minimal_emulator` credits
  them too, and gives the same 3,531). The families whose only test ran remote code are now tested against labelled
  transcriptions of that code under `tests/refs/` (read as text, never executed), or against the stock
  transformers / library classes the remote files build on: Qwen3.5-MoE / MemT, PLaMo-2,
  Hymba, Granite-Switch, GigaChat-3.5, LFM2-MoE / LFM3 / LFM3-RD, CENO, Motif-3, dQwen3.5, Nemotron-Labs-Diffusion,
  GPT-S3, Jet-Nemotron, Mini-K3, GKA-primed HybridQwen3, Youtu-LLM, Phi-4-mini-flash, AliceAI, AllGDN-Engram,
  EdgeRock, PseudoBrain, Mamba-3 MIMO, RWKV-5 / -6 / -7, Nemotron-Flash, GLM-SuperExpert, Agnes.
- The join (one host for all 3,906): h 16,384, 192 layers, kv/token 14,336, 128 query heads, 2.76M FFN units per
  layer; ~26.5T parameters, ~4.5T active, ~4.8x the largest real model (Kimi-K3.1-Pro, ~5.5T).
- The joined host, with its gen slot set per target, hosts 919 of the 942 shapes (3,877 of 3,906 models) in exact,
  payable and mixgap, and all 942 in capacity. The 23 shapes (29 models) it does not host are left open (the 17
  join features behind them are listed under "not in this release").
- The silu output gate (`UAttention.gate_silu`) and the activated gates with g_proj's bias, per channel or per head.

### Proofs and verification material in the repo

- `proofs/`: the Lean 4 + Mathlib library (namespace `EP`) and `proofs/lean/check.sh`.
- `verify/prenorm_rescue/`: the pre-norm compensator measurements (scripts and results: the RMS-range and
  reciprocal fits on seven models, the LayerNorm fold and parallel-block end-to-end runs on Pythia-160m).
- `verify/COVERAGE_PLAN.md`: the definitions of the coverage dashboard's 15 metrics (`verify/COVERAGE.md`).

### Recipes and the zoo

- Recipes: 3,334 models have a tested route in every framework (PyTorch, JAX, tinygrad, TensorFlow, DyNet;
  `graph/data/recipes.json`).
- The zoo page (`python -m graph.zoo_ref --out dist/zoo.html`, generated): 942 shapes, 3,906 models, plus
  `zoo_pairs.json` beside it (11,559 blocker texts).
- 14 snapshot models have no modelling code anywhere (6 model types) and are left unplaced.

## Verification status

- `python -m verify.r3.relcheck` (942 shapes): reflexive in every mode; 0 transitivity violations in exact,
  payable, mixgap and capacity; exact <= payable <= mixgap <= capacity with 0 pairs outside. Edges: exact 28,185,
  payable 39,076, mixgap 42,343, capacity 178,605.
- Z3 differential (`python -m verify.z3_relation --skip-hypothesis --skip-proofs`: the Z3 expressions against
  `emul_matrix` on every ordered pair of the 942 real shapes, 5 modes x 2 flag settings, the joined host as a host
  column): 0 disagreements in every run (exact 28,185 / payable 39,076 / mixgap 42,343 / capacity
  178,605 edges with the context and vocab axes off; the joined host column 0 disagreements); 0 real-data transitivity
  violations and 0 monotonicity failures.
- `proofs/lean/check.sh`: build OK, 740 theorems and lemmas, all within {propext, Classical.choice, Quot.sound}; the
  negative control is rejected.
- Edge table (`verify/EDGE_JUSTIFICATION.md`): headline rules PROVED 159, CODE 17, CATALOG (verified instance,
  theorem pending) 8, MEASURED 5, UNJUSTIFIED 0, REFUTED 0.
- Spot checks: 70 sampled headline edges built end to end (`verify/spot/results.jsonl`).
- Test suite: 2,969 tests collected; the fast suite (`pytest -m "not slow"`): 2,910 passed, 47 skipped, 11 xfailed,
  0 failed.
- Coverage dashboard (`python -m verify.coverage_report`) and its ratchet: every metric at or above `verify/coverage_baseline.json`;
  M11 (models carried end to end, no remote-code test credited) 3,531 / 3,906; M1, M9, M15 at 100 %.
