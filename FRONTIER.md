A slot difference with no currency blocks emulation; that includes a softmax host for an SSM / linear / hybrid target (the near-gap is measured not payable: `attn/mixer_gap_agreement.py`) and a non-sharing host for a cross-layer-KV-sharing target (the carry has a ~6e-2 pre-norm floor: `block/prenorm_carry.py`). Regenerate with `python -m graph.frontier`.

Secondary — *if every type wall were free* (`mode="capacity"`: capacity + the one-way AR ⊆ diffusion wall only): **49** (42 AR + 7 diffusion).
