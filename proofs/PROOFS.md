# Machine-checked proofs of the cookbook

Lean 4 + Mathlib, in `lean/EmulationProofs/`, over exact real arithmetic (no floating point).
Each theorem says that the host component with the constructed weights equals the target component for all inputs (exact), converges to it (limit), stays within a stated distance (bound), or cannot match it (impossibility).

Check everything with `lean/check.sh`. It runs `lake build`, rejects any `sorry` / `admit` / `axiom` / `native_decide`, runs `#print axioms` on all 740 theorems and lemmas (each uses at most `propext`, `Classical.choice`, `Quot.sound`), and runs the negative control. The negative control is `lean/NegativeControl/FalseVariants.lean`: wrong variants of the polarisation identity (`/2` for `/4`) and of the partial-RoPE base (exponent inverted), given the same proof scripts as the true ones. The checker must reject them. The library also proves that both variants are false (`EP.polarization_half_false`, `EP.partial_rope_wrong_base_false`).

Theorem names are in namespace `EP`. Files: `Position`, `Norm`, `Attention`, `MoE`, `Activation`, `Approx`, `Block`, `Walls`, `RopeRank`, `PreNorm`, `MLARope`, `RandomFeatures`, `LearnedAbs`, `Converses`, `Capacity`, `CapacityDepth`, `MLAHost`, `PosBias`, `ActLimits`, `AuditRules`, `ModelLimit`, `PreNormRescue`, `ActWidth`, `LimitKit`, `EpsLever`, `KVPack`, `MoERouting`, `LimitInstances`, `LimitInstances2`, `ActFits`, `Round2`, `Round2Rec`, `Round2Walls` (all `.lean`); `Common.lean` holds softmax attention, the hard-mask limit and the softmax perturbation bound.

## The eps lever: host norms switched off

A host norm the target lacks can be switched off as a limit: the writer into the norm divides by S, the norm weight becomes S√ε·w, and the host keeps its own ε > 0 (`EpsLever.lean`). With ε = 0 the norm is scale invariant and the lever does nothing.

## KV-head packing

## Where the formal statement needs a condition the cookbook does not state

Each condition comes with a converse: a theorem that the construction fails when the condition is violated (in brackets).

1. **dense ⊇ top-1 MoE (β → ∞).** The limit needs a unique argmax. At a tie, softmax(βz) stays at (½, ½) for every β (`soft_router_tie`), so the soft router never reproduces a tie-broken pick. Convergence is pointwise, not uniform near routing boundaries. [`soft_router_tie`]
   The construction also assumes a unit gate, i.e. renormalised top-1 (what `moe/dense_emulates_moe.py` builds). A top-1 MoE that multiplies by the router probability `p_{e*}(x)` (Switch-style, or Llama-4's sigmoid score) has the same third multiplicative factor that the row says blocks top-k > 1. [`hard_select_needs_unit_gate`: with gate p ≠ 1 the select output `Y_{e*}` is not `p·Y_{e*}`.]
2. **MoE → dense by tying experts** needs `Σ_{e∈T(x)} p_e(x) = 1`, i.e. renormalised top-k (`tied_moe_is_dense`). Without renormalisation (`norm_topk_prob = False`, e.g. Qwen-MoE and DeepSeek-V2-style routers) the tied MoE outputs `(Σp)(x)·F(x)`, which varies per token. For those, use the zero-router construction (`dense_sub_moe`). [`tied_moe_not_dense`: on a token with `Σp ≠ 1` and nonzero FFN output, the tied MoE differs from the FFN.]
3. **ALiBi ⊆ RoPE** holds for causal attention only. The frozen pair gives `−m(i−j)`, odd in i−j (`alibi_pair_odd`), while bidirectional ALiBi uses `−m|i−j|`. The content pairs must also be at frequency 0 (a buffer write, as for NoPE), or they keep rotating. [`alibi_host_not_bidirectional`: for every θ, the frozen-pair host cannot equal `q·k − m\|i−j\|` at both (0, 1) and (1, 0) unless m = 0, and `alibi_limit_not_bidirectional` says the same for the limit. `content_pair_rotates`: a content pair with cos ω ≠ 1 gives `cos ω ≠ 1` at distance 1.]
4. **sink ⊆ plain, and the ALiBi frozen pair** both need their constant channel in a zero-frequency (unrotated) pair. On a RoPE host whose every dim rotates, the sink logit becomes `s·cos((i−p)ω)`, which depends on the query position (`const_channel_rotates`). So the construction needs a spare head-dim pair with `inv_freq = 0` (a buffer write, allowed as for NoPE). [`sink_needs_zero_freq`: with cos ω ≠ 1 and s ≠ 0, the sink logit differs between query positions p and p+1.]
5. **swigluoai ⊆ SiLU** needs an up-projection bias, or a constant channel, to absorb the `+1`. It is exact only in the clamp regime (gate ≤ 7, \|up\| ≤ 7). [`swigluoai_gate_out_of_regime` (gate > 7), `swigluoai_up_out_of_regime` (\|up\| > 7, gate in (0, 7]), `swigluoai_needs_up_bias` (a bias-free up branch gives 0 at up = 0).]
6. **Learned-absolute positions are a wall only without a position-0 marker.** The single-layer statement is proved (`rope_cannot_learned_abs`). With a BOS token at position 0 (and nowhere else), two extra pre-norm blocks and 5 extra channels reproduce the learned-absolute embedding exactly over a bounded context, and the rest of the model follows (`learned_abs_two_block`, `learned_abs_model`). The pre-norm is handled exactly: a per-token pad equalises embedding norms, and a compensator channel equalises the norm across positions before the table is written. [`no_learned_abs_without_marker`: without a marker, no plain-softmax host of any depth works, because a constant input stays constant. A sink also breaks this (`sink_uniform_position`).]
7. **parallel ⊆ seq, norm-free:** the construction here uses (L+1)·d width for an L-block model, not 2d. This matches the comment in `block/parallel_residual.py`. That 2d is impossible is not proved. [Under a pre-norm the channel construction fails at any width: `parallel_sub_seq_prenorm_fails`, `prenorm_readout_obstruction`.]
8. **LayerNorm ⊆ RMSNorm** (already stated, made exact): the same ε on both sides; every residual writer post-composed with P, including the embedding (hence untied) and any sublayer-output norm's input; and biases in the host's first linear layers and lm_head whenever β ≠ 0. [`rmsNorm_eps_inj`, `layerNorm_ne_rms_other_eps`: with ε' ≠ ε, the folded RMSNorm misses LayerNorm on any input with a nonzero centred coordinate.]
9. **qk-norm ⊆ plain** is exact only in its regime. [`qknorm_out_of_regime`: if a token pair's RMS product differs from the folded constants and the plain logit is nonzero, the logits differ.]
10. **Partial-RoPE host ⊇ full-RoPE target** needs rot_h ≥ rot_t. [`partial_rope_too_few`.]

## Pre-norm rescue attempts

`prenorm_readout_obstruction` refutes carries whose carried vector does not move with the stream. It does not exclude hosts that compute compensating channels, as `learned_abs_two_block` does. `PreNormRescue.lean` covers those. Every impossibility below holds on any nonempty open set of residual states, i.e. for a construction that must work on a continuous range of activations. On a finite set of states (bounded context, finite vocabulary) an interpolating MLP is always exact, at a cost that grows with the number of distinct residuals. That is why `learned_abs_two_block` works: its residuals take only tokens × positions values. Numerics are in `verify/prenorm_rescue/` (`results/*.json`).

### The tools

| tool | theorem(s) | status | statement |
|---|---|---|---|
| the target's ε is a constant-norm budget | `const_norm_carry` | PROVED exact | Host residual `[x; z]` with `‖z‖² = S` the SAME for every input reaching the norm. Weight `√(d/(d+e))·w` on the stream and `ε' = (dε − S)/(d+e)` give the target's `RMSNorm_ε(x)` exactly. `ε' ≥ 0` iff `S ≤ dε`; scaling the stream by λ multiplies the budget by λ². With `ε' = 0` the extra channels are a pad that IS the target's ε. |
| carried channels come out divided by the token RMS | `const_norm_carry` (second part) | PROVED exact | Even with a fixed-norm carry, an extra channel reads as `wz ⊙ z / R`, where `R = √(d/(d+e))·√(‖x‖²/d + ε)`. That is exact up to a positive per-token factor: signs and thresholds survive, magnitudes do not. |
| a constant readout needs a channel ∝ the RMS | `const_readout_channel` | PROVED | If a normed channel reads a fixed `t ≠ 0` (q bias, sink logit, LayerNorm β, ALiBi slope), then `ζ² (m wζ² − t²) = t²(‖y‖² + mε)`, i.e. `ζ = λ√(‖y‖² + mε)`. |
| no equaliser with host ε = 0 | `eps_zero_no_equaliser`, `rmsNorm_zero_smul` | PROVED impossible | With ε = 0 and no pad, every sublayer write (MLP, attention, anything) is invariant under scaling of the token's residual. The new residual's squared norm is then a nonconstant quadratic on every ray segment. |
| no analytic or affine equaliser | `no_prenorm_rms_equaliser`, `no_bounded_analytic_equaliser`, `prenorm_write_analytic_bounded` | PROVED impossible | Covers any ε ≥ 0 with a positive norm argument (ε > 0 or a pad), and any sublayer analytic on ℝᵐ: SiLU / GeLU / GLU MLPs, attention as a function of one token, or an affine map (a ReLU MLP on one of its linear pieces). The write is analytic and bounded in the stream state, and the residual's RMS is constant on no nonempty open set of states. So the compensator `√(c − ‖x‖²)` of `learned_abs_two_block` does not extend to content-dependent residuals. Deeper stacks also have bounded analytic writes, so the core lemma covers them. |
| no analytic channel ∝ the RMS | `no_prenorm_homogeneous_channel` | PROVED impossible | A bounded analytic write equals `λ√(‖x‖² + c)` on no nonempty open set. With `const_readout_channel`, no analytic or affine pre-norm host gives an exact constant readout on content-dependent residuals. |
| vanishing-scale carry | `vanishing_carry_limit` | PROVED limit | Write the carried vector at scale δ. Magnitude consumers keep the 1/R factor. |
| exact constant writes in bias-free GLU hosts | `rmsNorm_zero_sq_sum` | PROVED | With ε = 0, `Σ_i (normed h)_i² = m`, so `2m` bias-free GLU units write an exact constant. That gives constant writes, but no constants inside activations. Bias-free ReLU / SiLU MLPs write no nonzero constant on an open set. |

**The approximation.** Use host ε = 0 and a pad κ with `κ² = dε_t`. The pad's normed coordinate is `t = √m κ/‖h‖`, a linear readout of the sublayer input, and the token RMS is `∝ 1/t`. Every magnitude rescue therefore reduces to a 1D approximation of `1/t` on the layer's empirical range, whose difficulty depends only on the RMS dynamic range `D = r_max/r_min`. ## Constants through a bias-free pre-norm (branch fr-bias)

`RmsChannel.lean`. Host residual `[x; κ; ζ]` over D = d + 2, host ε = 0, κ² = dε (the target's ε, `const_norm_carry`), r(x) = √(‖x‖²/d + ε). Construction and measurements: model_subsets `norm/rms_channel.py`, `dist/fr_bias.md`.

| rule | theorem(s) | status | statement |
|---|---|---|---|
| the RMS channel reads a constant | `rmsChannel_fresh_read`, `rmsChannel_const` | PROVED exact | With ζ = λ r(x) the host RMS is r(x)·s, s = √((d + λ²)/D), a constant: the stream reads w x/(r s) (the target's normalisation up to s) and ζ reads w_ζ λ/s for every token. So ζ is the bias column of every linear map of that sublayer (q / k / v / o via a constant value, gate / up / down, LayerNorm β, an lm_head bias, a sink's constant query, swigluoai's up + 1, a vanilla FFN's up = 1). Not a contradiction of `const_readout_channel`: ζ IS the channel ∝ RMS it requires. |
| refreshing the channel | `rmsChannel_refresh`, `rmsChannel_refresh_error` | PROVED exact | After the stream moves, the normed pad t = κ/R and stale channel a = ζ₀/R give r(x) = (κ/t)√((D − a²)/d), so ζ₀ + (κ/t)(λ√((D − a²)/d) − a) = λ r(x). κ/t is a 1-D reciprocal of one normed coordinate, approximated by k bias-free GLU units (an APPROXIMATION in k, not a fixed-width limit: `no_prenorm_homogeneous_channel` still excludes an exact analytic write). Fit errors e₁, e₂ of the two terms give λr(1 + e₂) − ζ₀e₁: they do not accumulate over refreshes. |
| a wrong channel | `rmsChannel_perturb` | PROVED bound | ζ = λ r u instead of λ r: the constant read is multiplied by f = u√((d + λ²)/(d + λ²u²)) with \|f − 1\| ≤ \|u − 1\|, the stream read by g with \|g − 1\| ≤ λ²\|u² − 1\|/d. So a fit error passes to the biases at most 1:1, and a stale channel (between refreshes) moves the stream by O(λ²/d) (λ = 10⁻³: below fp32). |
| the dominant constant channel | `dominant_channel_read`, `dominant_channel_rate`, `dominant_limit_not_normalised`, `one_sub_inv_sqrt_le` | PROVED limit; REFUTED as a construction | Residual [x; C], ε = 0: the scaled stream read is w x/√(1 + u) and the constant read w_C/√(1 + u), u = ‖x‖²/C², within (u/2)·\|w x\| and (u/2)·\|w_C\| of the norm-free affine read w x + w_C. That limit is degree-1 homogeneous in x, so it equals no fixed multiple of an RMSNorm read on both x and 2x (any ε ≥ 0, w x ≠ 0): a dominated host computes the NORM-FREE biased model, and its error tends to that model's error, not to 0 (measured: Qwen2.5-0.5B / stablelm-2-1.6b top-1 0% at every C; the C → ∞ model overflows in fp32). |

## Not done, with the reason

- an exponential (sub-Gaussian) concentration bound for random features (only the exact variance and Chebyshev are proved);
- the sizes of the pre-norm gaps (~1e−2 for parallel ⊆ seq, 6e−2 for CLA), which are measurements; only their nonzeroness is proved, for the channel/carry constructions;
- impossibility of parallel ⊆ seq or CLA ⊆ standard for EVERY pre-norm host: the theorems now cover carries and analytic / affine compensating channels (Pre-norm rescue attempts), but not arbitrary multi-layer hosts. Finite-input interpolation is always exact, at a cost exponential in the context;
- the full sink-based learned-absolute construction (only the head output is proved);
- necessity of the MoE ← MoE routing conditions against arbitrary hosts (only the duplication family is proved);
- certified bounds for the GeLU multi-unit fits (no computable Φ enclosure in Mathlib) and for the fits on [−160, 160];
- floors and gaps (GeLU ≈ SiLU 0.0139, mish 0.10, the activation and positional cross-matrices, MLA rank, RoPE-window), which are numerics and not provable as identities.
